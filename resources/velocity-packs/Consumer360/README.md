# Consumer 360 Velocity Pack

Pre-built data model for B2C consumer data management. Designed to centralize and master individual consumer profiles across systems, enabling profiling, identity resolution, and targeted marketing. Brings together duplicate consumer records from multiple source systems into a unified golden record.

## Entity types

| Entity type | Purpose |
|-------------|---------|
| Individual | Consumer profiles — the core entity type for this pack |

## What's preconfigured

- Match rules for Individual and Location entity types, including fuzzy name matching and exact address matching
- Survivorship groups and cleansers for standardizing names, addresses, and contact data
- Reference data lookup types (address types, status reason codes, and more)
- Social media as a nested attribute on Individual
- Preconfigured Hub UI for searching, segmenting, and managing consumer profiles
