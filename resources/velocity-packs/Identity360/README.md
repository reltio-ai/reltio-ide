# Identity 360 Velocity Pack

Pre-built identity resolution data model for managing individual profiles and their personal and professional relationships. Covers individuals, locations, and a rich set of relationship types for mapping how people connect — family, social, and professional networks.

## Entity types

| Entity type | Purpose |
|-------------|---------|
| Individual | Person profiles |
| Location | Physical addresses linked to individuals |
| Party | Abstract parent type for individuals |

## Relation types

| Relation type | Description |
|---------------|-------------|
| Spouse | Marriage relationship |
| Parent | Parent–child relationship |
| Sibling | Sibling relationship |
| domestic partner | Domestic partnership |
| Family | General family relationship |
| Friend | Friendship |
| Relative | Extended family |
| ReferredBy | Referral relationship |
| Manager | Management relationship |
| Assistant | Assistance relationship |
| Influencer | Influence relationship |

## What's preconfigured

- Match rules and survivorship groups for Individual and Location entity types
- Identity resolution configuration for deduplicating person records across source systems
- Preconfigured Hub UI for managing individual profiles and relationship networks
